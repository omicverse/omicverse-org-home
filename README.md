# OmicVerse.org Home

Static community homepage for `omicverse.org`.

The site positions OmicVerse as an open multi-omics community focused on:

- unified Python APIs for omics analysis,
- Python/Rust re-implementations of widely used R algorithms,
- interoperable data foundations,
- tutorials, benchmarks, and agent-ready workflows.

## Development

```bash
npm run build
npm run serve
```

Then open:

```text
http://localhost:4173
```

## Structure

```text
src/
  index.html
  packages.html
  ports.html          # R-port catalog (reads assets/ports.json)
  ports.js
  styles.css
  script.js
  assets/ports.json   # generated by scripts/build_ports.py
scripts/
  build_ports.py      # org → ports.json aggregator (+ port.yaml scaffolds)
  ports_overrides.yaml
docs/PORT_MANIFEST.md # port.yaml spec for py-*/rust-* repos
dist/
```

`dist/` is generated and can be deployed directly as a static site.

## R-port catalog (`ports.html`)

`src/ports.html` renders `src/assets/ports.json`, a generated catalog of every
`py-*` / `rust-*` repo in the org with its R → Python function map.

```bash
# regenerate (needs a GitHub token: $GITHUB_TOKEN or `gh auth login`)
python3 scripts/build_ports.py --out src/assets/ports.json

# write draft port.yaml files for repos that do not have one yet
python3 scripts/build_ports.py --scaffold /tmp/port-yaml-drafts
```

`.github/workflows/sync-ports.yml` regenerates the file daily. Port repos
describe themselves with a root-level `port.yaml`; the schema lives in
[docs/PORT_MANIFEST.md](docs/PORT_MANIFEST.md) and
[templates/port.template.yaml](templates/port.template.yaml).
