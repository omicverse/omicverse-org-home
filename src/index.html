Why OmicVerse

One surface. Verified methods. Ready for agents.

One API, AnnData throughout

The same ov.pp / ov.tl / ov.pl calls for every modality. scanpy pipelines plug in unchanged.

Trusted R methods, rebuilt

Pure-Python and Rust ports of CRAN and Bioconductor packages. No rpy2, no R install.

Checked against the original

Every port pre-registers a parity gate and runs it against the R reference before release.

Agent-ready

Skills, tutorials and report templates let analysis agents run the stack end to end.

Quickstart

Count matrix to clusters in eight lines.

Read, QC, normalize, embed and cluster with the same calls for every data type. The object stays AnnData the whole way, so scanpy, exports or an agent can take over at any step.

Read the docs Tutorials → 
$ pip install omicverse

import omicverse as ov
adata = ov.datasets.pbmc8k()
ov.pp.qc(adata, tresh={"mito_perc": 0.2, "nUMIs": 500})
ov.pp.preprocess(adata, mode="shiftlog|pearson", n_HVGs=2000)
ov.pp.scale(adata); ov.pp.pca(adata, layer="scaled")
ov.pp.neighbors(adata, use_rep="scaled|original|X_pca")
ov.pp.umap(adata); ov.pp.leiden(adata)
# adata.obs["leiden"] · adata.obsm["X_umap"]
